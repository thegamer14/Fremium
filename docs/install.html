Installation guide

Install Fremium.

Bring the full Fremium workspace into Spotify, then open the launcher whenever you want your listening tools nearby.

01 · Windows quick install

Run the PowerShell installer

Make sure Spicetify is installed and available on your PATH. Open PowerShell and run:

irm https://raw.githubusercontent.com/thegamer14/Fremium/main/install.ps1 | iex

The installer downloads the current project, enables the CustomApp, applies Spicetify, and creates the optional C:\Free Saves folder.

02 · Windows manual install

Install from a local clone

Use this route when you want to inspect or update the project yourself.

git clone https://github.com/thegamer14/Fremium.git
$source = "$env:USERPROFILE\Downloads\Fremium"
$target = "$env:APPDATA\spicetify\CustomApps\spicify-plugin"
New-Item -ItemType Directory -Force -Path $target | Out-Null
Copy-Item -Path "$source\*" -Destination $target -Recurse -Force
spicetify config custom_apps spicify-plugin
spicetify apply

Fully restart Spotify after the apply command finishes.

03 · Linux or macOS

Run the shell installer

Make sure spicetify, curl, and tar are available, then run:

bash <(curl -fsSL https://raw.githubusercontent.com/thegamer14/Fremium/main/install.sh)

Restart Spotify after the installer reports that Fremium was installed successfully.

04 · First launch

Open your Fremium workspace

After restarting Spotify, select the ◈ launcher to open the persistent window.

Select the ◈ launcher in Spotify
Choose C:\Free Saves if you want local QI files
Open Account to create or sign in to your Fremium account

The launcher stays available while you browse playlists, Home, search, and your library.

Before you start

Have these ready

  • Spicetify installed and available from your terminal
  • Spotify ready to restart after installation
  • Permission to create the optional Free Saves folder
